Personal Business Card

一个简洁、现代的个人名片网页，使用 HTML5 + CSS3 构建，用于展示个人头像、姓名、职业以及联系方式。

项目采用居中卡片式布局，并加入圆角、阴影和鼠标悬停动画，整体风格简约，适合作为个人主页、个人介绍页面或前端 HTML/CSS 入门项目。

⸻

✨ 项目特点

* 简约现代的个人名片设计
* 使用 HTML5 与 CSS3 原生开发
* HTML 结构与 CSS 样式分离
* 圆形个人头像
* 展示姓名、职业与联系方式
* 卡片圆角与柔和阴影效果
* 鼠标悬停时卡片轻微上浮
* 无需任何第三方框架
* 下载后即可直接运行

⸻

🛠️ 技术栈

* HTML5
* CSS3

🚀 如何运行

方法一：直接打开

下载项目后进入：

Personal Business-Card Webpage/Card web

然后双击：

index.html

即可使用浏览器打开个人名片网页。

方法二：使用 VS Code

1. 克隆仓库：

git clone https://github.com/allan-qiu/Personal-Business-Card.git

2. 使用 VS Code 打开项目。
3. 进入：

Personal Business-Card Webpage/Card web

4. 打开 index.html。
5. 可以直接使用浏览器运行，也可以安装 Live Server 扩展进行预览。
